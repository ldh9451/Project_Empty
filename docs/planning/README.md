# 새 게임 기획

새로 만들 게임의 기획 문서를 보관하는 폴더입니다.

- 게임 개요, 핵심 재미, 플레이 흐름, 시스템과 콘텐츠 규칙을 작성합니다.
- 주제별로 Markdown 파일을 만듭니다. 예: `게임-개요.md`, `전투-시스템.md`
- 구현 결과는 `../implementation/`에 기록하고 관련 문서를 서로 연결합니다.
