# 새 게임 구현 기록

기획을 실제로 구현한 과정과 결과를 정리하는 폴더입니다.

- 구현한 기능, 변경 파일, 검증 결과와 남은 작업을 기록합니다.
- 기획 문서와 같은 주제의 파일명을 사용합니다. 예: `전투-시스템.md`
- 관련 기획은 `../planning/`의 문서로 연결합니다.
- 완료한 내용과 아직 구현하지 않았거나 검증하지 않은 내용을 구분합니다.

## 문서 기본 양식

아래 내용을 새 `.md` 파일에 복사해서 사용하세요.

```markdown
# 구현 제목

- 상태: 진행 중 / 구현 완료 / 검증 완료
- 관련 기획: [기획 제목](../planning/기획-파일명.md)
- 작성일: YYYY-MM-DD

## 구현한 내용

## 주요 변경 파일

## 구현 방식과 선택 이유

## 실행 및 검증 결과

## 기획과 달라진 점

## 남은 작업과 알려진 문제
```
